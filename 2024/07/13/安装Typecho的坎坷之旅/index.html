安装 Typecho 的坎坷之旅

胖胖2024-07-132025-09-04

前言

按照家里原来的网络架构，Typecho 应该跑在一台独立的服务器上，再由连着外网的 Nginx 做 SSL 加密和反向代理。但装了 Handsome 主题的 Typecho，页面里有些组件会单独向服务器发请求，结果从公网用 HTTPS 访问时，浏览器控制台报 Mixed Content：HTTPS 页面里混进了 HTTP 请求。

前后调了三天也没解决。就算想办法让这些组件请求公网域名，也没法控制它们请求哪个端口（家宽的 443 端口不通，其他服务走的都是 88 端口）。最后干脆直接把 Typecho 装在反代服务器上。

下面的步骤不包括反向代理的配置，也不建议给装了第三方主题的 Typecho 套反向代理。

2024 年 11 月 30 日更新：现在已经通过一台有公网端口的服务器，内网穿透到家里的反代服务器。如果你有公网 IP，并且 80 和 443 端口可用，就可以像反代普通网站一样反代 Typecho，用什么插件和主题都没问题。

整个安装过程基于 Ubuntu 24.04 LTS，其他系统请酌情参考。

结语

Typecho 本身装起来并不复杂，大部分时间都花在折腾反向代理上了。踩的坑主要是 MySQL 的权限和 PHP 的版本：直接 apt install php 不会装上 PHP-FPM 和 MySQL 扩展。
